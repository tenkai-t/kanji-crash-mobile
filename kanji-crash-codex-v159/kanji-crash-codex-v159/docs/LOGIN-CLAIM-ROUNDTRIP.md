# ログイン報酬受取後の再発修正（2026-11-01）

ブランチ: fix/login-claim-roundtrip。所有者の公開承認により、検証済み修正を公開用ブランチcloudflare-testへ反映する。Cloudflareの配信切り替え完了は別途確認が必要。本番DBの直接操作・実ユーザーへの付与/修復は未実施。

## 再発報告と再現できた原因

所有者から「修復後、ログインボーナスを受け取ると再発」「文が違った」と報告。実際の差額・端末/サーバーの最新状態は取得していない。

ローカルで、POSTがサーバーに確定した直後、応答を端末へ届ける前にプロフィールを非同期更新すると、従来のJSON.stringify(gameState)全体比較が失敗した。サーバーには報酬が加算される一方、端末は古い受取回数と残高のまま保護状態になった。既存プロフィール/実績の通信完了処理もgameStateを更新しsaveStateするため、画面操作なしでも同じ競合が起こり得る。前回の端末優先修復はその時点の不一致を解消する機能であり、次の受取時のこの経路を防いでいなかった。

## 変更

- 付与要求の前に小さな受取前記録をlocalStorageへ確実に保存。新規キーkanji_login_bonus_pending_v1:<guestId>。既存保存キーやIDは変更しない。
- 記録は当該ゲスト、受取前ordinal/revision、文・かけら、サーバー提示の報酬、文/かけら/ordinalを除くsnapshotのSHA-256。token・復元コード・所持品全体は含めない。記録保存に失敗したらPOSTを始めず、未付与のままにする。
- サーバーが返す状態が、記録した受取前snapshot＋正式な1回分の報酬と完全一致することを、ハッシュ、revision、ordinal、数値で確認する。
- 確認できた場合のみ、最新の端末状態へ文・かけらの報酬差分とordinalを適用。受取中のプロフィール変更、文の消費、ほかの進行を維持する。サーバー保存との差が残る場合は後続の通常保存で同期する。
- 反映前にordinalを再確認。端末保存を先に確定し、同じordinalへ再付与しない。書込はsaveStore.writeを使用し、別タブの変更や破損保護をreplaceで解除しない。
- 応答消失・再読み込み後も同じ受取前記録から検証できる。サーバーで未確定に見える場合も、遅れてPOSTが確定する可能性があるため記録をすぐ削除しない。受取済みordinalが端末に保存できた場合、またはrevision進行により古い要求が確定できなくなった場合に記録を解消する。
- 記録がない過去の不一致や、サーバー側で無関係な項目が変わった場合は差額を推測して加算しない。従来の完全一致回復と明示的な端末優先修復は残す。
- 通信/保存の例外で、確定済みの保存を画面再描画の失敗と混同しない。保存状態を再描画し、必要な後続保存を予約する。

サーバーの付与処理、受取履歴、日付、7回の報酬量、二重付与防止の一意制約、確率、コストは変更しない。旧SitesとそのDBは対象外。

## 検証

- 修正前の再現: サーバー確定後にプロフィールだけを変更するとconflict=true、localOrdinal=0、端末状態変化による上書き停止。修正後はconflict=false、localOrdinal=1、2,000文の受取完了。
- tests/login-roundtrip.mjs: 独立メモリDBの合成プレイヤーで、以前の不一致を明示修復→2〜8回目の受取→保存→再読み込みを連続検証。受取通信中に毎回プロフィール更新と文の消費を重ね、確定報酬だけの加算、端末進行・ID維持、正しいかけら、サーバー残高/ordinal、受取件数を確認する。
- 同テストで、応答消失、状態確認も失敗した後の再読み込み、受取前記録の容量エラー（POSTなし）、付与前503→端末進行の保存→再確認・再試行、7回目から次サイクルへの切替を確認。
- 日をまたいだ状態はローカルSQLiteの合成受取日だけを過去へ移して作る。JST午前0時の判定自体は既存tests/login-bonus.mjsおよびpopupテストで別途確認する。本番の日時やDBは変更しない。
- tests/header-login-recovery-browser.cjs: 応答消失・再試行・再読み込み、ID/所持維持、証明と一致しないサーバー状態を上書きしない回帰。以前の「ローカルで文が増えただけ」を真の不一致とするfixtureは、サーバーの無関係な段位変化を返すfixtureへ変更。安全なローカル進行の維持はroundtripで検証する。
- tests/login-bonus-popup-browser.cjs、tests/ipad-login-layout-browser.cjs: 自動表示、受取画面、日付境界、通信失敗、大きな文字/縦横/受取前後の表示。
- npm ci、ビルド、既存test:migration 17件成功。verify:sourceは旧取得時スナップショットとの差分を検出。比較基準は変更しない。

Chromiumと独立した合成データでの検証。iPhone/iPad Safari実機、本番で既に生じた残高差の解消は未確認。既存の差額を今回のコードだけで自動的に追加・回収しない。
