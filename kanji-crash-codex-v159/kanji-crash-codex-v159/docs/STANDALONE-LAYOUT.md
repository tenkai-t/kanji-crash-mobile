## 調査と変更

既存のapple-mobile-web-app-status-bar-styleはblack-translucentで、ホーム画面起動時にOSのステータスバーとWebコンテンツが重なる構成だった。ヘッダー自体の背景ぼかしは前回すでに解除済み。実機のぼやけは未再現のため、この設定が直接原因だとは断定しない。

- ステータスバーの指定をblackへ変更。OS側の透過を避ける。
- display-mode: standaloneまたはiOSのnavigator.standaloneでホーム画面起動を検出し、その場合だけ既存safe-area-inset-topに8pxを追加。ヘッダーとmainをまとめて下げる。transformによる画面拡大縮小はしない。
- 下部5メニューは通常64px＋下部safe areaだった。ホーム画面起動時は56px＋safe areaへ縮める。横向きの低い画面では従来の48px＋safe areaを維持。
- nav自体の下部paddingをなくし、safe areaを各ボタン内のpaddingへ移動。別の空白帯を作らず、背景とタップ領域を下までつなぐ。文字・アイコンはホームバーの上に保つ。メニュー背景のぼかしもこの起動モードだけ解除。
- 通常ブラウザーの余白・メニュー高さは維持。メニュー数、遷移先、保存キー、データ、報酬・ゲームロジックは変更しない。

ホームバーが使うOSの安全領域をゼロにすると操作が重なるため、その部分は残す。余白全体が完全に消えることは保証しない。iOSはホームアイコン側にステータスバー設定を保持する場合があり、既存アイコンでの適用は実機確認が必要。保存データ保護のため、アイコン削除やサイトデータ削除を検証手順にしない。
