# 操作性・説明・画面配置の改善（2026-10-25、未公開）

作業ブランチ: `feature/usability-overhaul`。今回の依頼は実装と検証まで。
GitHubへのpush、本番公開、本番DB操作、旧Sitesへの操作は行っていない。
前の依頼で追加済み・未公開の10連確定演出を維持し、その差分を引き継いでいる。

## 画面ごとの変更

### 遊ぶ

- CPU対戦を短い説明→難易度→対局準備ボタンの順にし、報酬と難易度の詳細をその後の折りたたみにまとめた。
- 初回CPU案内の役割をCPUカードの説明に統合し、同じ対戦を始めるボタンの重複を除いた。最初の勝利後の召喚・編成案内と進捗保存は維持。
- 他モードも概要と開始操作の後に報酬の詳細を配置。貸出文字のスコア競争、連戦、特殊能力の攻略、お題の達成という違いを短い説明にした。
- 320x568を含む4サイズで、通常表示時にCPU対局準備ボタンが初期表示と下部ナビの間に収まることを確認。
- クリック後は既存の対局準備を開き、自動で戦闘を開始しない。

### 編成とボタン

- 通常の移動先を「CPU対戦の準備へ」、準備中の編集では「対局準備に戻る」と明示。
- 同じ既存ハンドラーを使い、相手の確認や編集した編成の反映を維持。
- 入れ替えと外すは48px以上にし、間隔を広げて補助操作の外すを控えめな色にした。
- 閉じる、補助操作、summary、ヘッダー設定、プロフィールも原則44px以上を確保。
- ボタンとタブの長文は折り返し、単純な文字縮小で収めない。

### 錬成

- 装飾を小さくし、「1．素材を選ぶ」「2．消費内容を確認」の順に配置。
- ロック中・編成中・アイコン用の文字が選べない理由を選択一覧の近くに表示。
- 組み合わせ・一括操作は「錬成方法の違い・組み合わせ・一括操作」にまとめ、従来の操作・費用表示・保護説明をそのまま残した。
- 既存の消費確認画面と確定操作を維持。素材の消費・抽選・獲得処理は変更しない。

### 説明と用語

- 各画面の先頭に目的と操作を短く表示。
- ルビを読みと能力、文をゲーム内通貨、水準を文字の区分として入口で補足。
- ヘルプにも用語説明を用意し、CPU段位ポイントと対人RPを区別。
- 召喚の長い補足やモードの詳しい報酬は折りたたみに整理。召喚ボタンの価格、消費前の素材確認、受取条件は削除していない。
- 報酬・コスト・確率・段位判定の数値は変更せず、CPU段位ポイントの説明は既存のKanjiCpuPoints.gainによる更新を維持。

### 記録と設定

- 下部メニューは5項目のまま。
- 記録の上部に「報酬」を置き、ログインボーナスとギフトコードを直接開けるようにした。
- ギフトの元のformノードとイベントを維持。コード入力→内容確認→受取の段階は変えず、確認だけでは付与しない。
- ヘッダーの「設定」から音・BGM、名前と見た目、保存・復元へアクセス。
- 音と見た目は既存ダイアログを開き、保存・復元は記録にある元のパネルへ移動する。復元UIや認証情報を複製しない。
- 保存状況バッジ、復元コード、過去のバックアップ、ファイル保存・復元、現在データが置き換わる説明を維持。
- ヘルプと投稿案内は記録末尾の折りたたみにまとめた。

## 保持したもの

保存キー、プレイヤーID、復元コード、所持文字、育成、編成、配置、装備ルビ、お気に入り、段位、実績、ギフト履歴。
報酬量、抽選確率、能力値、消費コスト、試験条件、保存/復元API、データ保護処理。
10連確定演出の希少以上/超希少以上/伝説表示、元素の誤判定防止、手動開封、スキップ、中央演出、動き軽減。
新たなレア保証抽選や再抽選は追加しない。

## 検証

- npm ci、Cloudflare向けビルド、既存test:migration 17件。
- tests/usability-browser.cjs: Chromium 320x568、390x844、768x1024、1024x768。
  - 最初のCPU開始導線、対局準備→編集→準備に戻る、タップ領域。
  - 設定→音/見た目/保存・復元、記録→報酬、ギフトの内容確認で未付与。
  - ナビゲーションで所持・文・編成・ゲストIDが変わらないこと。
  - 主要5画面の横はみ出し、300体の所持、空状態、検索、長文、本文・ボタンの拡大。
- tests/beginner-next-step.cjs: CPU/召喚/編成への案内とデータ不変。
- tests/ten-guarantee.cjs、tests/ten-guarantee-browser.cjs: 追加済みの確定演出の回帰。
- tests/bgm-switching-browser.cjs: 設定経由で3曲の実再生、切替、失敗、再試行。
- tests/login-bonus-popup-browser.cjs: 自動表示、同日抑制、報酬入口、日付境界、失敗時再確認。
- tests/ipad-login-layout-browser.cjs: 受取前後の安定、文字拡大、記録の入口。

ローカルの独立したテストサーバーと新規状態のみを使用。検証途中で旧ローカルサーバーが停止したため、8811で起動し直して対象テストを再実行した。
実機iPhone/iPad Safari、実際のオンライン利用者間対戦は未確認。ブラウザーのサイズ・タッチエミュレーションを実機確認として報告しない。
verify:sourceは従来スナップショットとの差分を検出するため不一致。比較基準は変更していない。
