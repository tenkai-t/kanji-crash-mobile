| 大 | 衝撃波 | large | 大きな体。発射後の最初の衝突で、近くの別の相手へ勢い40%の衝撃波。届く範囲も拡大。1発射1回。 |
| 十 | 四方撃 | cross | 最初の衝突後、上下左右の近くにいる別の相手へ直角に進路変更。1発射1回。 |

| 弾 | 跳ね返り | circle | 最初の衝突で跳ね返り、衝突前の勢い100%で進み、0.5秒間は空気抵抗を60%軽減。1発射1回。 |

| 合 | 結束 | circle | 近くの別の自分が発射すると、発射方向にいる近くの相手へ0.18秒後に追撃。1発射1回、追撃は連鎖しない。 |
