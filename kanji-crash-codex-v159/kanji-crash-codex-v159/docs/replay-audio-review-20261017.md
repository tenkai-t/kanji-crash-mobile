# 漢字クラッシュ：リプレイ動画の音声追加・確認用報告

2026年10月17日。既存サイトの未公開修正版。本番公開は行っていません。

## 実装内容

- 動画保存に「ゲームの音を入れる」と動画用音量（0〜100％、初期60％）を追加。ゲーム全体の音とは独立した、その画面での設定です。保存キーは増減していません。0％では音声トラックがあっても無音です。
- 専用Web Audioの出力先を録画用MediaStreamに接続。マイク・カメラ・画面収録の権限は求めません。生成中にスピーカーからは流さず、完成動画を再生して確認できます。
- 音声時計を映像にも使用。音声は先読みして一度だけ予約し、遅延が大きい場合は失敗として停止します。
- 音量の余裕、コンプレッサー、ソフトリミッター、短いフェードを追加。密集する通常効果音は最大4音に制限し、勝敗音は優先します。すべての同時発動音が個別に鳴るとは限りません。
- 音付きはMP4（H.264/AAC候補）を優先し、WebM（VP9/Opus、VP8/Opus等）へ対応判定で切り替えます。実際のコンテナと音声トラックのヘッダーも確認し、確認できなければ音付き成功とは表示しません。拡張子だけの変更はしません。
- 音声準備・録画失敗時は「音なしで保存し直す」を表示。従来の無音経路を使えます。
- 中止・画面非表示・画面を閉じる・別タブへの移動時は録画と音声を終了。音声ノード、トラック、タイマー、キャンバス、Blob URLを解放します。共有取消後は完成動画を保持します。

## 再現する音と限界

| 出来事 | 使用する音・時刻 |
| --- | --- |
| 発射 | 既存の発射音。各ターン開始に合わせる |
| 能力発動 | 既存の錬成音を動画用の合図として流用。記録された能力イベント時刻に合わせる。元の対局に専用能力音が記録されているわけではない |
| 撃破・落下 | 既存の衝撃音。記録フレームの落下状態への変化に合わせる。厳密な衝突時刻とは異なる |
| 勝敗 | 既存の勝利／敗北音。結果表示開始に合わせる。引き分けは現在のゲームと同様に敗北側の音 |
| 個別の衝突 | 衝突イベントの記録がないため再現しない |
| BGM | 既存実装にないため追加しない |

既存の効果音はコード内で発振器から生成しており、外部音声素材は見つかりませんでした。第三者の音源ファイルや新たなBGMは収録しません。独立した素材ライセンス表示は確認できておらず、権利を法的に保証するものではありません。

## 利用方法・端末による制限

動画保存欄で音と音量を選び、「動画を保存」を押します。対局と同じ速度で実時間の作成が必要です。画面を開いたまま待ち、完了後にプレビューを再生して音を確認してください。

iPhone／Androidともブラウザが示す実行時の対応状況で形式を選びます。MP4対応を一律には保証しません。「共有して保存」で端末が表示する「ビデオを保存」「ファイルに保存」などを選択します。共有非対応時はダウンロードを使います。WebMは写真アプリで扱えない場合があるため、対応する再生アプリを使用してください。

音声トラックの検査は収録の存在を調べるもので、聴覚的な正しさまでは保証しません。未対応・初期化失敗時は無音で再試行できます。ブラウザから写真アプリへの直接保存は保証しません。
